# Environment texture sources

All textures in this directory were downloaded from [Poly Haven](https://polyhaven.com/)
on 2026-08-07. Poly Haven publishes its assets under the
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) license.
Attribution is not required, but source information is retained here for auditability.

License statement: https://polyhaven.com/license

The texture files are the 1K JPG variants reported by the Poly Haven public API.
`normal-gl.jpg` contains the OpenGL normal map. The HDRI is the 1K Radiance HDR
variant and is used only for scene reflections and image-based lighting.
