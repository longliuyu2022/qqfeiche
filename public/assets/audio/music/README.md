# 比赛随机歌单

把已获授权的 `mp3`、`ogg` 或 `m4a` 文件放在此目录，并在
`manifest.json` 的 `tracks` 数组中登记。每场比赛会随机选择一首并循环播放。

当前工作区已登记 8 首用户提供的 MP3，文件名已规范化为 ASCII，原曲名保存在
`manifest.json` 的 `title` 字段中。发布网站或 Android 安装包前，请确认这些音频
具有公开再分发授权；QQ 音乐下载记录本身不等于再分发许可。若没有授权，请移除
这些 MP3 并将 `tracks` 设为空数组，播放器会自动回退到程序化 BGM。

示例：

```json
{
  "tracks": [
    { "file": "track-01.mp3", "title": "Track 01" },
    { "file": "track-02.ogg", "title": "Track 02" }
  ]
}
```

公开网站或 Android 安装包只能分发你拥有授权的音频；不支持 DRM 或加密音频。

## 音频文件不入库

`.gitignore` 已排除本目录下的 `*.mp3`、`*.ogg`、`*.m4a`：再分发授权未确认，音频
只保留在本地工作区，部署时单独投放服务器。`manifest.json` 和本文件仍入库，歌单
配置保持版本管理。

因此新克隆的仓库里没有音频文件。`race-playlist.js` 取不到文件时会回退到程序化
BGM，构建和部署脚本都不校验这些资源，缺文件不会导致失败。若要恢复完整歌单，把
`manifest.json` 中登记的文件按同名放回本目录即可。
