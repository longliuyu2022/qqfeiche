# 地图建模优化实测说明

本次接续会话 `01a07c2a-0534-7c82-b0f8-5257cb2a8304`，基于当前 `1.11.0 (21)` 工作区生成 Android 测试包。网页预览为 `http://localhost:4181`；安装包为 `../apk/neon-apex-scenic-preview-20260908.apk`。

雪岭、峡谷和海岸重新制作了连续地形、山体轮廓与路基。树木和环境地标按地面高度放置；峡谷增加分层岩壁与石拱，海岸使用较低的崖壁和展开的棕榈叶。三图护栏改为连续短节结构，带立柱和反光片，并保留近道开口。

七张地图新增路侧弯道箭头，修正 HUD 左右方向；标牌朝向适配正向、反向、镜像赛道，支柱延伸至实际地面。

实机建议按下面的顺序试跑：

1. 在计时赛中各跑一圈雪岭、峡谷和海岸，留意山体、植被、路基是否悬空或挡住赛道。
2. 驶入与驶出近道，检查护栏开口是否清楚、能否顺畅通过。
3. 切换反向和镜像赛道，比较路侧箭头、右上角导航与真实弯向是否一致。
4. 在手机横屏、竖屏以及均衡、高画质下试跑，观察帧率、发热、转向、漂移和氮气操作。记录出现问题的地图、方向、画质和路段即可。

代码验证已通过：全量 Node 测试、ESLint、生产构建；最后的支柱修正另通过三图两档画质、镜像接地与七图三方向的定向回归。最终画面、帧率和驾驶手感按你的要求留给实机验证。

玩法后续优先建议：增加有清楚视觉提示的路面抓地力差异；让近道的入弯要求与节省时间相匹配；给训练、反向／镜像赛道补充专属挑战和奖励。本轮已实现的玩法改善是提前判弯与道路边界识别。
